# 🟡 Pac-Man Game (React + TypeScript)

A modern implementation of the classic **Pac-Man** game built using **React**, **TypeScript**, and **Vite**.
The project focuses on clean architecture, game logic, and state management while keeping the UI simple and responsive.

---

## ✨ Features

* 🎮 Classic Pac-Man gameplay
* 👻 Ghost movement with basic AI logic
* 🍒 Pellets & power pellets
* 📊 Score tracking system
* 🏆 Persistent leaderboard using `localStorage`
* ⚡ Fast development setup with Vite
* 🧩 Modular and readable code structure

---

## 🛠️ Tech Stack

* **React**
* **TypeScript**
* **Vite**
* **HTML / CSS**
* **LocalStorage** (for leaderboard persistence)

---

## 📁 Project Structure

```
src/
│── components/     # Reusable UI components
│── screens/        # Game screens (Start, Game, Leaderboard)
│── utils/          # Game logic & helper functions
│── constants.ts    # Game constants
│── types.ts        # TypeScript types
│── App.tsx         # Main application
│── index.tsx       # Entry point
```

## 🚀 Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/pacman-final.git
cd pacman-final
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Run the project

```bash
npm run dev
```

Open your browser at:
👉 **[http://localhost:3000](http://localhost:3000)**
